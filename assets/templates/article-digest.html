仓颉蒸馏术

把一本 300 页红队手册，压成 11 个 AI Agent 随叫随到的技能

用 Codex + Cangjie-Skill（仓颉），把英国国防部《Red Teaming Handbook》全本硬核内容，精准沉淀成 11 个红队心智与方法论 Skill——不是摘要，是变成 Agent 随时能调用的"技能"。

核心逻辑链
1

干了什么

300 页手册 → 拆成 challenge-assumptions、phishing-simulation 等 11 个独立 Skill，用到哪个唤醒哪个，不再把整本书塞进上下文。

2

以前多烂

PDF 搜关键词只给页码、自己记笔记懒得翻、问模型容易凭印象乱补——三种老办法都低效。

3

Stage 1.5 常识过滤（最关键）

提取之前先删废话：删定义、删重复案例、删跑题故事、删"只讲是什么不讲怎么做"。300 页砍掉约 60%，剩 40% 才是真方法论。

4

11 个 Skill 长什么样

每个是统一结构的 .md：Overview / When to Use / Methodology / Decision Framework / Checklist / Example / Common Pitfalls。

5

实测防钓鱼邮件

蒸馏完直接拿 phishing-simulation 实测：AI 用红队官思维框架分析心理弱点与认知偏差，而非扫关键词。

6

跟 book-to-skill 的区别

① Stage 1.5 先删废话再拆；② 方法论导向（跨章合并）而非按章节拆；③ 每个 Skill 生成后 5 项质量检查。

7

顺手做了插件

封装成 Codex 插件 Doc-to-Skill Distiller（MIT 开源，1193 行），任何文档都能一键转可调用的 Skill。

适合谁

定位
不替代读书，更像是把一本书做成 Agent 里的"随手翻"——方法论、决策框架、检查清单收好，写方案少翻半天文档。

仓颉不仅在蒸馏一本书，它在把人类任何沉淀的文档，一键转化为 AI Agent 动态演练的超能力。
