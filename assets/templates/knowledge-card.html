agent-security-check v2

AI 安全Skill 工程部署门禁

Agent 部署前的五层攻击面安全自检工具：带对抗性判定与证据收据，专防「静默降级洗钱门」。纯标准库实现，零外部依赖。

CORE POINTS · 核心要点

1五层攻击面扫描隔离 / 网络 / 供应链 / MCP / 凭证，逐层机器可检
2对抗性判定层每条发现带机器可检证据收据，不靠主观断言
3High 级不可静默降级material downgrade 防「洗钱门」——降级需显式留痕
4完整性门 + 确定性 closure跨次账本记录每次运行，结果可复现可追溯
5显式降级通道--concur --downgrade-reason 必须写理由，否则阻断

类比：像代码合并前的 CI 红绿灯 + 审计日志。墨方守在闸门口——发现 High 风险不让过，除非你举着写清理由的降级牌；每次放行都记入账本，事后能查「谁、何时、为何」放过了什么。
