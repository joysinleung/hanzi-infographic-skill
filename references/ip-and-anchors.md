# 视觉 IP「墨方」+ 认知锚点配图（借鉴 ian-xiaohei-illustrations MIT，自创实现）

> 借鉴小黑(MIT) 的**方法**：用一个贯穿系列的视觉 IP + 「认知锚点」配图策略 + 原创隐喻 + 美学门控。但 **IP 形象必须自创**——不复用"小黑"（黑豆+白点眼+细腿），否则侵权。

## 一、墨方（Mofang）IP 设定

**自创差异点（与小黑明确区分）**：
- 小黑 = 黑豆 + 白**圆点**眼 + 细腿 + 荒诞冷幽默。
- 墨方 = **圆角方块**身体 + 单只**方块眼**（方块内嵌小方块，非圆点）+ 网格纹理皮肤 + 冷静"数据守护者"气质，可变形为数据块/漏斗/闸门。更系统感、少荒诞。

### 角色定义
墨方是中文信息图里的固定视觉符号，代表"正在认真运转的数据/系统操作员"。它不是吉祥物、不是贴纸，而是承担图里某个具体动作的主体。

### 外形（SVG 实现，见 `assets/ip/mofang.svg`）
- 圆角方块身体（深色，带细网格纹理）。
- 单只方块眼（白底方块内嵌小黑方块），表情空、冷静、认真。
- 可加细短线手/脚（几何化，不卡通）。
- 轮廓规整带极轻手绘抖动，避免机械矢量感。

### 性格
认真、克制、系统感；像在白板草图里真负责某工作的操作员。不卖萌、不幼稚、不荒诞。

### 动作原子（认知锚点用，SVG 片段复用）
| 动作 | 含义 | 用法 |
|------|------|------|
| 搬运（carry） | 把数据/素材从一处移到另一处 | 内容生产、信息汇聚 |
| 警示（warn） | 举牌/亮红，标风险/坑 | P0 待办、风险板块、⚠️ 注意项 |
| 守门（gate） | 站在闸门/漏斗口 | 过滤、质检、安全门禁 |
| 记录（log） | 拿笔/本记东西 | 复盘感想、待办索引 |

### 禁止
- 不画成小黑的样子（黑豆+白圆点眼+细腿）。
- 不过度可爱、不表情包、不闪亮眼睛。
- 不让墨方只是站在角落看——它必须承担动作。
- 不抢文字可读性（点睛图尺寸克制）。

### 判断标准
去掉墨方后，该板块的核心意思仍完全成立 → 墨方太装饰，需重写让它成为动作主体。

## 二、认知锚点配图策略（不平均用力）

1. 解析源文档章节，找 **2-4 个重点板块**（关键决策 / P0 待办 / 风险 / 核心概念）。
2. 只在重点板块配墨方点睛 SVG；非重点纯文字。
3. 一张图（一个板块）只讲一个核心动作/结构，不堆砌。
4. 颜色克制：红=问题/结果，橙=主路径/箭头，蓝=补充（可不用）。

### 实现方式
模板里预留 `.anchor` 容器，渲染时在重点板块的 `.block-title` 右侧或卡片角放墨方 SVG（inline 或 `<img src="assets/ip/mofang.svg#warn">`）。MVP 用 `daily-review-panorama` 的"后续建议 P0"和"复盘感想 ⚠️"两块配 `warn` / `log` 动作。

## 三、配色语义（与小黑四色一致，并入 styles.md）
黑/墨=主体、红=问题/结果、橙=主路径/箭头、蓝=补充系统状态（克制）。

## 四、美学门控（防呆板/防模板化）
- 墨方承担动作，非装饰。
- 画面不堆节点、不堆箭头、不堆标签。
- 不为凑密度乱加装饰 SVG。
- 重点板块有记忆点，非重点干净。
